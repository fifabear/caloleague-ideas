④러닝벨트 정비 — 청소·장력·트래킹

공식 Owner's Guide·Service Manual에 적힌 순서 그대로입니다. 추측 없이 원문 기준.

1. 매일: 세척

  1. 물 + 순한 비누(또는 매트릭스 승인 세정제)를 적신 천으로 전체를 닦습니다. 알코올·암모니아가 든 세정제는 금지입니다.
  2. 매뉴얼 원문은 "soap and slightly damp cloth only; never use solvents"입니다. 물을 직접 뿌리지 말고 살짝 적신 천으로 — 전장부·모터 커버로 물이 흘러들면 안 됩니다.
  3. 벨트를 들어 벨트 안쪽(데크 면)과 사이드레일 틈의 먼지·마그네슘 가루를 마른 천으로 제거합니다. 고저항 슬레드 훈련은 마찰 분진이 빨리 쌓입니다.
  4. 닦은 뒤 마른 천으로 물기를 완전히 제거하고, 벨트 위에 윤활제·광택제를 뿌리지 않습니다.
모델별로 갈립니다 — 윤활
  • TM534(S-Drive M)·TM533(C)·TM535C(P): 윤활 불필요. 매트릭스 시설용 가이드는 "S-DriveP/TM535, S-DriveM/TM534, S-DriveC/TM533 DO NOT require lubrication"이라고 명시합니다. 벨트가 이미 윤활 처리(pre-lubricated)되어 나옵니다.
  • 구형 TM529(S-DPT-01)만 3개월마다 데크에 100% 실리콘 오일을 지그재그로 바르고, 벨트 위에는 바르지 않습니다. 서비스 매뉴얼의 윤활 항목은 이 구형 모델 기준입니다.
  • 내 기구가 TM534라면 실리콘을 추가로 바르는 것이 오히려 미끄러짐·분진을 만듭니다. 시리얼로 형번을 먼저 확인하세요.

2. 장력 — 미끄러지면 ¼턴씩

  1. 후면 엔드캡 안쪽 8mm 육각 볼트 2개가 뒤 롤러 위치를 조정합니다(동봉 T렌치 사용).
  2. 브레이크 두 개를 최대 저항으로 둡니다(슬레드 8단·스피드 11단).
  3. 하단 핸들바를 잡고 슬레드 자세로 벨트를 밀어 봅니다. 벨트가 미끄러지면 양쪽 볼트를 같은 양(¼턴) 시계방향으로 조입니다.
  4. 미끄러지지 않을 때까지 반복합니다. 과조임은 롤러·베어링을 죽이므로 한 번에 ¼~½턴을 넘기지 않습니다.

3. 트래킹 — 한쪽으로 쏠리면

  1. 벨트가 프레임 양옆에 같은 간격으로 놓여야 합니다. 한쪽에 닿아 있으면 가동하지 말고 양쪽 볼트를 반시계로 약 1회전 풀어 벨트를 손으로 평행하게 옮깁니다.
  2. 다시 같은 양만큼 조인 뒤, 3 mph(약 4.8km/h) 이하로 걸으며 관찰합니다.
  3. 오른쪽으로 흐르면 오른쪽 조이고 왼쪽 풀기(각 ¼턴), 왼쪽으로 흐르면 반대로. 몇 분간 유지될 때까지 반복합니다.
  4. 앞커버와 벨트 가장자리가 평행한지로 최종 확인합니다. 조정 중에는 3 mph를 넘기지 않습니다(매뉴얼 주의문).

4. 교체 신호와 교체 난이도

교체 신호

가장자리 풀림·섬유 벗겨짐, 표면 광택(유리질화), 한쪽만 닳음, 장력을 조여도 고저항에서 미끄러짐, 벨트 밑면 갈색 번짐.

교체 절차

사이드레일 → 뒤 롤러 → 데크 → 앞 롤러 우측 나사 2개 순으로 분해한 뒤 벨트를 들어냅니다. 재조립 후 장력·트래킹 재조정 필수.

누가 하나

매뉴얼은 "부품 탈거·교체는 자격 있는 서비스 기술자"가 하도록 규정합니다. 데크·롤러를 함께 여는 작업이라 출장 AS가 안전합니다.

교체 주기

이 매뉴얼의 정비 주기표에는 벨트 교체 주기가 없습니다(일일 세척·하네스 점검만 규정). 주기가 아니라 상태로 판단합니다.

  2. 기구 본체와 같은 금지선을 지킵니다 — 알코올·암모니아·솔벤트 금지. 표백제·섬유유연제도 피합니다.
  3. 패드 안쪽 땀·소금기는 미지근한 물에 적신 천으로 여러 번 눌러 빼고, 완전히 말린 뒤 장착합니다.
  4. 세척 후 버클 작동과 박음질을 다시 확인하고 사용합니다.
